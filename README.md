# りすかメーカー

コード進行と雰囲気を選ぶと、**リリースカットピアノ(リスカ)**のフレーズを毎回新しく書くツールです。
MIDI で書き出して、そのまま DAW に持っていけます。

手順の元ネタは井荷麻奈実さんの動画
[日本一参考にならないリリースカットピアノの作り方](https://www.youtube.com/watch?v=5ABIgWACxfs) です。
動画の工程をそのままエンジンの工程にしています(特定の曲の旋律をコピーしているわけではありません)。

## 起動

`start_risuka.bat` をダブルクリックするか、`index.html` をブラウザで開いてください。インストールは要りません。

ピアノの音は起動時にネットから読み込みます(Salamander Grand Piano、約 28 ファイル)。
つながらないときは内蔵の合成ピアノに自動で切り替わります。**MIDI の中身はどちらでも同じ**です。

## 使い方

1. コード進行を入れる(下の「書き方」参照)
2. 雰囲気を選ぶ。選んだ瞬間に生成されます
3. 再生して、気に入らなければ「生成する」(キーボードの `G`)。再生を止めずに差し替わります
4. 気に入った小節は**小節番号をクリックして固定**すると、残りだけ作り直せます
5. MIDI を書き出して DAW へ

### コードの書き方

| 書き方 | 意味 |
|---|---|
| `F G Em Am` | 1コード1小節 |
| `F G \| Em Am` | `\|` で小節を区切る(中は均等割り) |
| `C:3 G:1` | `:拍数` で長さを指定 |
| `C - G -` | `-` で前のコードを伸ばす |
| `%` | 前の小節の繰り返し |
| `N.C.` | ピアノ全体を止める(ブレイク) |
| `IV V iii vi` | ローマ数字(キーを選んだときの基準) |

`F#m7(b5)` `C7(b9,13)` `G/B` `F△7` `Cø` `Csus4` `Cadd9` なども読めます。全角で打っても大丈夫です。

### DAW での鳴らし方(動画の「0. 音源の準備」)

MIDI を読み込んだら、サンプラーの **ENV 1 AMP のリリースを 0** にします。これだけだと高音域に余韻が残ります。
実際のピアノは高音域にダンパーがないので、サンプル自体に余韻が入っているからです。
動画では Logic の Sampler で、マッピング画面から隠れている **Envelope 1 Offsets を表示して右端の R を全部 0** にしています。
これで高音域まで切れます。

## どうやって「毎回違うのに破綻しない」を実現しているか

勉強用にしくみを書いておきます。

### 1. 音ではなく「動機」を作っている

固定フレーズを並べると必ず飽きるし、音をサイコロで決めるとでたらめになります。そこで**リズムと輪郭だけの動機**を作ります。

```
動機 = リズム(3+3+2 など)+ 輪郭(上行、ジグザグ、跳躍→下行 など)
```

音高は決めていないので、コードが変わっても**そのコードに合わせて実体化**できます。
同じ動機が別のコードで鳴ると、人間の耳には「同じフレーズの移動」(ゼクエンツ)として聞こえます。
これが「まとまって聞こえる」理由です。さらに4小節を `A → A' → B → C` のような形式で組みます。

### 2. 作って、採点して、選ぶ

1フレーズにつき旋律候補を 14 本作って採点し、全体でも 5 テイク作って採点します。主な採点基準はこうです。

- 強拍にコードトーンがあるか(アボイドノートは大きく減点)
- 跳躍の後を反対方向の順次進行で受けているか
- 大きな跳躍が続いていないか
- 最高音がフレーズの後半に来ているか、最後は安定した音に着地しているか
- 動機がほどよく繰り返されているか
- 雰囲気の目標音数に近いか

一番良いものを必ず選ぶのではなく、**点数に応じた確率で選びます**(ソフトマックス)。
必ず1位を選ぶと似たものばかりになるからです。連続して生成するときは、直前までの旋律と似ていないものを選びます。

### 3. コードごとにスケールを判定している

進行全体からキーを推定し、コードごとに使ってよい音を決めています。

- `Em7`(キー C)→ フリジアン。F と C は避ける
- `FM7` → リディアン。避ける音なし
- `E7 → Am` → 短調へのドミナントなのでフリジアンドミナント
- `Db7 → C` → 裏コードなのでリディアンドミナント

画面の「コードごとに使った音階」に今回の判定が出ます。

### 4. 動画の工程がそのまま5段階

画面のタブで**各工程の途中経過を見て、聴けます**。

| 工程 | やっていること |
|---|---|
| 1 仮ベース・仮コード | ベース音形を出発点に、コードを走り書き |
| 2 フレーズ | ベース・内声・トップに動機を置く。主張させたい動きは 8 度や 5 度で重ね、足りなければ 2 重にする |
| 3 埋め尽くす | 2〜4 拍の短い動機を継ぎ足して飽和させる。過度にうるさいくらいで丁度いい |
| 4 隙間 | コードの変わり目とベースが聴こえるよう音価を切る。**聴こえてほしいのに埋もれる旋律の直前を一瞬無音にする**(ロールの ↓)。ベロシティは内声 80〜90、外声 100〜115 |
| 5 完成 | ぶつかる音(短 9 度の持続など)を取り除く |

ピアノを 1 台で複数の楽器のように使う技法なので、ピアノ以外の音を足さなくても成立します。
ガイドドラムは、ノリを確かめるためのおまけです。

## 雰囲気

雰囲気は固定フレーズの集まりではなく、判断基準の組み合わせです(`src/moods.js`)。音数、シンコペーション、テンションの量、音域、ハモりの頻度、内声の質感の配分などを持っています。自分で増やすのも簡単です。

| 雰囲気 | テンポ | 特徴 |
|---|---|---|
| 動画準拠 | 174 | 動画の手順をいちばん素直に再現。1小節約 50 音 |
| 疾走 | 182 | 刻みと上行で前へ前へ |
| 切ない | 146 | 下行と余白。音数は少なめ |
| きらきら | 168 | 高音域のアルペジオ |
| ダーク | 170 | 低音域と半音進行 |
| 爆発 | 190 | 音数最大、ハモりも最大 |
| おしゃれ | 118 | テンション多め、スウィングあり |
| 透明 | 154 | 4 度・5 度の堆積とアルペジオ |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `src/theory.js` | コード解析、キー判定、コードスケール |
| `src/moods.js` | 雰囲気の定義 |
| `src/composer.js` | 作曲エンジン本体 |
| `src/midi.js` | MIDI 書き出し |
| `src/audio.js` | 再生、WAV 書き出し |
| `src/ui.js` | 画面 |
| `tests/engine.test.js` | 品質テスト。`node --test tests/engine.test.js` |
| `tools/dump.js` | 生成結果を文字で確認。`node tools/dump.js "F G Em Am" douga 123` |

テストは動作確認だけでなく音楽的な品質も見ています。強拍の安定音率、事故音の割合、順次進行の割合、シードごとの旋律の違い、隙間が本当に無音か、などです。
